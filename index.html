State-Conditioned Steering

Steering that evolves with the model’s reasoning state.

Conventional activation steering often reuses one fixed direction throughout generation. My recent work instead recomputes the intervention update from the reasoning state currently being visited.

The backbone model remains unchanged; a lightweight predictor estimates the next additive update at reasoning checkpoints during inference.

Inference-time flow
1 · Current reasoning state Read the model’s internal state
→
2 · Predictor Compute a state-matched update
→
3 · Next generation span Apply the new direction

At the next checkpoint, the model state is read again and the update is refreshed. The intervention changes with the trajectory rather than staying fixed.
